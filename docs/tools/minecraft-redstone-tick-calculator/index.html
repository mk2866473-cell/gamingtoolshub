What is the difference between a Game Tick and a Redstone Tick?

Minecraft updates its main game loop 20 times per second (1 Game Tick = 50ms). Redstone components update every other tick, or 10 times per second (1 Redstone Tick = 2 Game Ticks = 100ms).

Why does an observer output a 1-redstone-tick pulse?

When an observer detects a block state change, it outputs a 2-game-tick (1 redstone tick = 0.1s) pulse.
