Midpoint Circle Algorithm (Bresenham Discrete Voxelization)

Rasterizing a circle onto a square grid uses the midpoint circle theorem: a block at coordinate (x, y) is selected if (x - cx)² + (y - cy)² ≤ (radius + 0.5)². For thin outlines, pixels are filtered by testing whether neighboring orthogonal blocks also satisfy the perimeter boundary condition.
