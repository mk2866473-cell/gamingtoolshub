Voxel Ellipse Equation (Bresenham Ellipse Algorithm)

A grid block at coordinate (x, z) relative to center (cx, cz) satisfies the discrete ellipse condition if: (x - cx)² / (Rx + 0.5)² + (z - cz)² / (Rz + 0.5)² ≤ 1.0 Where Rx = Width / 2 and Rz = Length / 2.
